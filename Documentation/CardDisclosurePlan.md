# Report 與 Checklist 卡片收合

```text
TaskProgress
├─ Report TaskList → TaskCard／ReportPointerCard
├─ ChecklistApp → 工作項目卡 → checks
└─ 共用 CardDisclosure → 標題區、切換按鈕、可隱藏內容區
```

## 行為

每張頂層卡片在標題左側提供三角形切換：展開為 ▼，收合為 ▶；兩種清單均在「工作項目」下方工具列提供單一全體收展圖示（上箭頭收合／下箭頭展開）。預設展開以保持現有閱讀方式；收合只隱藏詳細內容，保留標題、狀態與進度。Report 指路卡保留導航入口、載入／錯誤提示。

狀態由各清單以穩定 ID 保存於本次頁面生命週期；篩選、排序與資料儲存不重設，以 sessionStorage 按分頁與文件保存，重新載入還原收合狀態；儲存不可用時仍保留本頁記憶體操作。不寫入 report、checklist 或儲存歷史。共用控制只擁有顯示與無障礙語意，不擁有任務資料或寫入操作。

內容以 hidden 隱藏而非卸載，保留新增項目與其他輸入草稿。原生 button 提供鍵盤操作、aria-expanded 與 aria-controls。編輯、導覽與 checkbox 不以整張卡片點擊觸發收合。

全體圖示每次點擊只套用一次收展並清除先前單卡例外；之後各卡仍可獨立切換，不被全體狀態鎖住。

Report 編輯模式只在標題右側、完成數旁顯示一個狀態下拉選單，直接取代預覽的狀態標籤。標題下方只保留優先級選單，不重複呈現狀態；狀態變更沿用原編輯草稿、儲存與復原流程。

Checklist 下一步跳轉先展開目標工作項目，再恢復篩選與定位；收合卡片的進度統計以完整工作項目計算。

## 驗收

- Report 普通卡、指路卡與 Checklist 工作項目皆使用同一個收合控制。
- 單卡與全部切換可用；篩選／排序不遺失本頁的選擇。
- 收合保留標題／狀態／進度，指路卡導航與診斷仍可見。
- 收合／展開不產生資料儲存，草稿不因內容卸載丟失。
- 下一步跳轉可展開並聚焦被收合的 check。
- Browser、Desktop Checklist 與 Viewer 資產皆重建；實機鍵盤／窄螢幕／草稿驗收後排。

## 選取與換位

共用 CardList 擁有獨立單卡選取、拖曳落點與本頁暫時排序，沿用既有 capsule-order 的 ID 正規化與搬移運算。所有排序模式皆可點擊卡片空白或文字區選取，顯示選取框；互動控制不改變選取。切換排序保留選取，拖曳結束也不清除。鍵盤聚焦卡片後 Enter／Space 選取、Escape 取消。卡片不顯示獨立拖曳把手；滑鼠從卡片空白處拖曳，觸控／手寫筆長按卡片標題、摘要或空白處後拖曳，短滑仍可捲動。滑鼠文字選取、子項、連結、checkbox 與編輯控制保留原操作。目標上半部／下半部分別插入之前／之後，Alt＋↑／↓ 使用相同換位規則並聚焦原卡。

工作項目下方工具列的單一排序圖示依序循環：順排（既有狀態及優先級排序）、逆排（反轉既有排序）、不排（本頁暫時換位）。順排圖示為向下箭頭與逐項縮短的橫條，逆排反向；不排為無箭頭、不等長橫條。模式本身按文件保存，但不排的手動順序只留在目前頁面，重新載入即恢復來源投影，舊 localStorage 手動順序不再讀取或更新。篩選時只重排可見卡片的槽位，隱藏卡片留在原位置；新增 ID 接在暫時順序之後，刪除 ID 不再參與移動。

Browser 以 report scope／report ID 或 Checklist scope／task／round 隔離模式、釘選等檢視設定。Desktop Checklist 缺少穩定完整檔案識別時只保留本頁設定，避免同名檔案共用。

驗收：空白處前後拖曳與鍵盤移動可用；篩選隱藏位置不變；模式跨文件隔離；不排不寫檔且重新載入清除暫時順序；Report 順排的來源換位依下節驗收。Checklist／Decision 不提供原始文件重排，保留不排的暫時換位。

### 順排寫回原始順序

Report 在有編輯權限時可於順排拖曳卡片，改動 `report.json` 的 `tasks` 陣列順序。相同狀態分組且卡片優先級相同就能互換；不改優先級來配合落點。不同群組不顯示有效落點，模型也拒絕跨優先級請求。釘選與 Next 卡固定，唯讀環境及逆排不啟用來源換位。

來源換位只重排本次可見、同級卡片占用的原始槽位，隱藏、固定及其他優先級卡片的槽位與所有內容原樣保留。以穩定 ID 指定 before／after；原位放下不寫入。Report 自己提供資料與儲存回呼，共用 CardList 不讀寫檔案。

預覽模式沿用子項換位的編輯工作階段、最新來源比對、If-Match 與原子保存；來源過期或儲存失敗不採用新順序。成功後重新投影來源，可 Ctrl＋Z 復原、Ctrl＋Y 重做。編輯模式則是 Editor Core 的一步草稿，沿用謹慎模式、取消、儲存與 Undo／Redo，不另開保存機制。驗收輪次見 [順排換位清單](../checklists/report-card-source-reorder.checklist)。

### 卡片同級判定

未完成卡片的排序與同級換位資格只看卡片自身的優先級，同級保留原始資料順序。子項即使有不同優先級，也不影響整張卡的位置或有效落點；未完成子項在卡片內仍依自己的優先級排序。原生滑鼠拖曳至有效落點時，顯示前／後位置的水平預覽線。修訂後的往返與原生手勢驗證見 [卡片優先級清單](../checklists/report-card-priority-only.checklist)。

### 已完成卡片與子項

未釘選的已完成卡片一律位於未完成卡片之後，不參與優先級排序。完成區保留來源資料中既有的完成順序，不因順排、逆排、不排或狀態標籤的群組位置而反轉或穿插。完成與未完成卡片分屬不同來源換位群組；卡片內三種結束狀態的子項由[結束子項堆疊](ReportItemOrderingPlan.md#結束子項堆疊)決定順序。

使用者明確釘選已完成卡片仍可置頂；已完成卡片不會因舊 Next 再被提到未完成卡片上方。完成時單次取消釘選的規則由 [完成事件](CardPin.md#完成事件) 擁有，驗證見 [完成事件清單](../checklists/report-card-completion.checklist)。

## 可見性控制

排序圖示右側提供點擊／長按選單，包含四個圖示：睜眼「啟用」依各卡 hidden 設定顯示；閉眼「全體關閉」暫時隱藏全部卡片且保留各卡設定；斜線眼「禁用」顯示所有符合篩選的卡片並隱藏單卡眼睛；「重置」清空所有 hidden 設定並回到啟用。預設禁用。

排序與可見性共用 [IconChoice](IconChoicePlan.md)，由該設計擁有浮動列定位與操作規則。不提供查看隱藏項目／套用隱藏按鈕，也不實作透明度或疊牌。

單卡眼睛在三角形與標題／完成框之間，只有啟用時顯示。隱藏保持元件掛載，不寫來源檔。Browser 按文件 key 在 sessionStorage 保存；Desktop 缺少 key 時僅本頁。下一步取消目標隱藏並展開；若全體關閉則先回啟用。換位依目前模式處理，隱藏槽位保持原位。

「清空結果」在底部儲存列的最右端，排在復原、重做、謹慎模式之後，按鈕尺寸與列內其他按鈕相同；它無法復原，所以會先跳確認框。第一張卡片右上角保留給搜尋框，不放這顆按鈕。它只把 `[manual]` 實機檢查重設為未執行並清除 Observed／Resolved，Agent 檢查結果保留；有未儲存變更時停用，原因放在提示。Desktop transport 提供既有 reset 協定，與 Browser 使用同一份 UI、確認框、草稿限制與失敗回報。

## 清單標題與篩選排列

Report、Checklist 與決策頁共用 CardList 的標題及工具列容器。上列以 .75rem 粗體顯示「工作項目」，同列的排序／篩選標籤為 .65rem 一般字重，空間不足可換行。全體收展、排序與可見性圖示放在下列，兩列間距為 3px；標籤的選取亮暗、hover 亮框與拖曳行為保持不變。

## 已完成子項目預覽

每張 Report 任務卡的已完成區預設只顯示陣列前 1 項（最新完成在上）。超過 1 項才顯示置中、帶向下箭頭的「顯示更多（N項）」，N 為未顯示的剩餘項數；展開後顯示全部並改成向上箭頭「收合」。各卡獨立控制，唯讀與編輯模式一致，不改變資料、排序、篩選或進度統計；重新載入回到 1 項預覽。
