# IconChoice 圖示選擇元件

## 系統階層與關係

```text
TaskProgress Report／Browser Checklist／Desktop Checklist
└─ CardList 工具列
   ├─ 排序：擁有順排／逆排／自由排序及保存
   ├─ 可見性：擁有啟用／全關／禁用及重置操作
   └─ IconChoice：觸發、浮動選項列、定位、鍵盤與指標操作
      └─ icon slot：由使用端提供圖示
```

## 目標與責任

把可見性選單和排序按鈕共用的互動集中，讓目前選項與觸發圖示正確對齊。元件只回報選項 ID；業務狀態、資料保存、排序與卡片顯示仍由 CardList 擁有。透明度與隱藏疊牌不在本輪範圍。

## 設定

| 設定 | 值與行為 |
|---|---|
| items | 唯一 id、可讀 label；kind 為 action 時代表一次性動作 |
| value／onChoose | 外部目前值／選擇回呼，元件不自行保存值 |
| interaction | cycle：點擊循環；picker：點擊或長按選擇；both：點擊循環、長按選擇 |
| orientation | horizontal／vertical |
| placement | aligned／adjacent |
| icon slot | 接收 item，供觸發按鈕與浮動選項共用 |

使用列舉避免兩個 bool 產生無法互動的組合。動作項目出現在選項列，但不參與循環，也不會成為目前狀態。

## 定位與操作

aligned 將目前選項中心對齊觸發按鈕中心，例如 `[a b (c) d]`，水平／垂直皆適用。adjacent 保留觸發按鈕並排除列中目前選項，例如 `(c) [a b d]`，水平優先向右、垂直優先向下；空間不足改另一側。靠近視窗邊界時整列平移到可視範圍，優先確保選項可操作；內容過長可捲動。

長按 300ms 開列 → 移至選項 → 放開套用；放開於列外取消。短按依 interaction 行為處理。浮動列開啟後，可直接點選；方向鍵依排列方向移動焦點，Home／End 跳首尾，Enter／Space 選擇。Escape 取消並回到觸發按鈕，Tab 離開與外部點擊關閉。視窗縮放、捲動或失焦取消尚未完成的手勢，避免套用錯誤位置。取消與選擇後還原焦點；外部點擊保留外部焦點。

## 使用與遷移

排序採 both＋vertical＋aligned，保留原點擊循環；可見性採 picker＋vertical＋aligned，保留四選項語意，reset 為 action。兩者共用元件，沒有產品名稱分支；既有儲存 key 與卡片狀態不改變。

## 驗收

- 三個入口共用元件，排序與可見性原有行為保持。
- 水平／垂直、對齊／端點定位可配置，選項不越出可視範圍。
- 點擊、長按放開、取消、鍵盤均可用；長按不多觸發一次 click。
- reset 不參與循環或成為選中狀態。
- 三份前端資產建置成功，實機對齊與操作手感另行驗收。

## 規模

Volume: 約 200 行共用元件，替換現有選單互動及排序按鈕，重建三份資產。
Precedent: 新共用互動邊界；兩個已存在的使用端驗證抽象。
Proof: 選項運算定向測試、三入口建置、獨立複核及實機驗收。
